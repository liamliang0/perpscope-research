理解 HYPE 与 ASTER 的竞争，
先把数据口径对齐。

从“交易是否活跃”，追到“资金有没有留下、业务是否赚钱、Token能否捕获价值”。这是我借助 Codex 做出的研究工具与交付样例。

研究从一个具体问题开始

Hyperliquid 和 Aster 的增长，是否足以支持对协议竞争力及 Token 价值捕获的判断？

我把这个问题拆成交易活动、持仓规模、费用/收入和Token数据，再检查指标能否放在一起比较。

这份样例能回答什么

  • 两家协议在选定指标中的相对位置
  • 哪些数字来自不同业务范围
  • 哪些判断还缺历史或第一方数据

同一个竞争问题，换个指标再看

以下仅为 Hyperliquid 与 Aster 两家之和，不是全市场份额。

Hyperliquid Aster

最值得展示的三个核验判断

持仓口径

官方 OI 与同源 OI 分开使用

样例中 Hyperliquid 官方 OI 为 $13.07B，同源数据为 $8.37B。跨协议份额采用同一个标准化数据集，官方值只作交叉核对。

价值捕获

母协议收益，不能直接当永续业务收益

Aster 可取得的持有人收益属于母协议范围；与永续业务口径的数字不直接计算高低或估值优劣。

历史覆盖

快照可以建立基线，不能冒充趋势

没有足够连续历史时，7日/30日成交量保持 N/A。该样例没有发出基于变化率的趋势信号。

事实

保留每项指标的数据源、接口、采集时间与业务范围；展示值沿用原报告的精度。

解释

成交、持仓与收入一起改善，才更有理由继续研究增长质量；单个快照不证明因果。

未知

用户留存、补贴成本、隐私功能采用等，需要第一方或额外研究数据，本样例不假装已经知道。

本份报告的检查结果

  • Hyperliquid成交量API覆盖默认永续市场，不自动包含全部HIP-3市场。
  • 两家OI份额使用同源数据，不混合官方与第三方口径。
  • 永续业务、母协议、Token层级分别标记。
  • 缺失一方数据时，不把缺失当零计算份额。
  • 历史不足时，不给出7日/30日趋势结论。
